# Scope and evidence

Primary workflow references checked 15 November 2026:

- https://help.filestage.io/en/articles/2562896-submit-your-review-decision — decisions on a file version.
- https://help.filestage.io/en/articles/7872784-chapter-3-managing-versions — version management and history.
- https://help.filestage.io/en/articles/1459683-manage-review-links-for-files-and-versions — latest-version review links.

Scope: one project with a fixed set of reviewer slots; immutable PDF/image versions; each reviewer retrieves a version and approves or requests changes; uploading a new version resets current review state while retaining older decisions. Export records with hashes and timestamps. Do not claim legal signatures, verified identities, complete Filestage parity or current market ranking.

Provisional name Approval Folio: GitHub `approval-folio in:name` search returned no results. Version Verdict and Revision Desk had apparent collisions and were rejected. Broader naming review remains.

Distribution plan: a synthetic agency brand-guideline PDF with two reviewer slots demonstrates the stale-approval problem. Ship a visual local walkthrough, versioned download and reproducible self-hosting recipe. Only after publication/acceptance, evaluate a useful agency workflow integration or an eligible factual directory listing using its current contribution rules. No external submission or endorsement is claimed.

Image normalization is reused from our MIT-licensed Review Dots component. The product remains an independent checkout with its own license, CI and history. No public creation, push, release or deployment is authorized for this new candidate yet.
